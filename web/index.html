    ParcelKindRestore

    Control Plane Restore Sequence

    etcd and kubeadm files are not a one-click onto the live data-dir. Follow this order on the node.

    1. Stop every API server first.
    2. Restore etcd into a new data-dir (never the live one).
    3. Point etcd.yaml hostPath and kubeadm-config dataDir at that dir.
    4. Bring back /etc/etcd only if that tree existed on the node.

    See docs/K8S-RESTORE.md.

    House · Shared Engine

    One Kopia, restic, or borg directory on this cell. Whole cluster, several namespaces, several compose projects, or several containers share deduplication here. Run a bag now still packs this satchel even when tenant copies exist.

    Control Plane is the etcd keyspace plus kubeadm files. It is the whole cluster. Leave it on for operator disaster recovery. Namespace filters below still share this engine.

    House Scope

    Empty Kubernetes namespaces means every namespace this cell can see, plus etcd when Control Plane is on. Named namespaces (one per line) still share the house engine. Empty Docker include means every container on this engine. Host paths are this node only — Swarm tasks and Kubernetes pods on other nodes need a cell on those nodes.

    Database Dumps

    Dump first, then hash. Each database is its own parcel. Restore one dump without the rest of the bag. A failed dump fails that row only.

    Cadence
    House Off-Side Locations

    The shared engine can copy unique packs to more than one remote. Each location has its own Off-Side Mode. Locked Packs is the default for stores like B2 that charge extra for reads and deletes.

    Porter · Ingest

    List and put. No delete. Paths live on each location card above.

    Steward · GC

    Delete and lifecycle. Lives on the maintenance host. A cell that can load these keys is mis-packed.

    Tenant Copies

    A separate engine directory per customer or service. Their off-side bag never contains house data or another tenant. Extra local disk and CPU. The house bag still runs.

    No tenant copies. House uses the shared engine for everything you ticked above.
